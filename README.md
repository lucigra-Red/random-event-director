# 随机事件导演

为 SillyTavern 聊天加入偶发情境，让日常、探索或冒险多一点变化。支持自定义事件风格和导演预设。

## 安装

1. 在酒馆打开 **扩展 → 安装扩展**，粘贴以下地址：

   ```text
   https://github.com/lucigra-Red/random-event-director
   ```

2. 安装后刷新页面，在 **扩展设置** 中展开 **随机事件导演**。

已手动安装过的用户请使用原安装方式更新，避免重复安装。

## 开始使用

1. 打开角色聊天，连接你平时使用的 AI。
2. 勾选 **开启本聊天的随机事件导演**。
3. 等待事件池准备好，或点击 **生成 / 重新生成事件池**。
4. 正常聊天，事件会按设置的概率出现。

想主动触发一次时，点击 **立即掷骰**，再正常发送消息。这个按钮本身不会发送 AI 回复。

每个聊天需要分别开启。关闭后即可继续普通聊天。重生成同一条回复会保留原来的事件安排。

## 常用设置

| 设置 | 怎么用 |
|---|---|
| 随机事件概率 | 默认 25%；想让事件少一些就调低，频繁一些就调高 |
| 事件池目标数量 | 默认 6，新手保留默认即可 |
| 使用当前酒馆 API 的当前模型 | 默认勾选；取消后可选择或填写同一连接下的其他模型 |
| 补充世界观 | 填写地点、背景、禁忌和重要规则，帮助事件贴合故事 |

生成事件池会额外调用 AI。想检查候选内容，可以展开 **查看事件池（可能剧透）**。

## 使用预设

展开 **导演预设管理**，选择预设后点击 **应用到本聊天**。

- **副 AI 事件生成提示词**：描述你希望出现的事件风格，例如轻松日常、探索线索或低强度冲突。保留 `{{count}}`。
- **主 AI 隐藏注入模板**：描述事件应如何融入剧情。保留 `{{event}}`。
- **保存预设**：保存并应用；**另存为**：保存一份副本；**恢复默认**：回到默认配置。
- **导入 / 导出 JSON**：分享或备份导演预设。导入后还需要选择并应用。这里使用导演专用预设文件。
- **副 AI 酒馆生成参数预设（可选）**：选择副 AI 使用的酒馆参数预设；事件风格仍在上面的提示词中填写。

`{{char}}` 表示角色名，`{{user}}` 表示玩家名；注入模板还可使用 `{{title}}`（事件标题）和 `{{type}}`（事件类型）。不熟悉提示词时，直接使用默认预设即可。

预设库可在不同聊天中使用；各聊天的选择独立保存。切换预设后，新事件使用新设置，已经准备好的事件保留原安排。

可以下载 [旅馆日常示例](examples/旅馆日常.json)，在 **导入 / 导出 JSON** 中导入体验。

## 没有出现事件？

- 检查当前聊天是否已开启导演，AI 连接是否正常。
- 事件池为空时，点击 **生成 / 重新生成事件池**。
- 不是每轮都会触发；可点击 **立即掷骰**，再发送消息体验。
- 面板显示错误时，先检查模型和连接设置。支持酒馆的 Chat Completion 和 Text Completion 连接。
